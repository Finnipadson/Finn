# Zusammen spielen übers Internet – kurze Anleitung

So spielst du „Clean the Skyscraper“ mit bis zu zwei Freunden, auch wenn sie woanders wohnen.

## 1. Spiel bauen und an deinen Freund schicken

1. Im Projektordner `export.bat` doppelklicken und warten, bis „Fertig“ dasteht.
2. Im Ordner `export` liegt jetzt **`CleanTheSkyscraper-Spiel.zip`** (ca. 50–60 MB).
3. Schick diese Zip-Datei an deinen Freund (z. B. über WeTransfer, Google Drive oder einen USB-Stick).
4. Dein Freund entpackt die Zip in einen beliebigen Ordner und startet **`CleanTheSkyscraper.exe`**.
   - Wichtig: Die drei `.dll`-Dateien müssen im selben Ordner wie die `.exe` liegen (sie sind in der Zip dabei).
   - Windows fragt beim ersten Start vielleicht „Der Computer wurde durch Windows geschützt“ → auf **„Weitere Informationen“** und dann **„Trotzdem ausführen“** klicken.
   - Fragt die Windows-Firewall nach, auf **„Zugriff zulassen“** klicken.
   - Dein Freund braucht **kein** Epic-Konto.

## 2. Spiel erstellen (du bist Gastgeber)

1. Spiel starten → im Hauptmenü **„Mehrspieler“**.
2. Oben deinen Namen und deine Farbe wählen.
3. Bei **„Übers Internet (mit Code)“** auf **„Spiel erstellen und Code bekommen“** klicken.
4. Nach ein paar Sekunden erscheint ein großer **6-stelliger Code** (z. B. `K7MP2Q`).
   Mit **„Code kopieren“** kannst du ihn direkt in WhatsApp/Discord einfügen.
5. **„Ins Spiel“** – du spielst schon, während die anderen beitreten.
   Den Code siehst du jederzeit oben rechts in der Spielerliste und im Pausenmenü (Esc).

## 3. Beitreten (dein Freund)

1. Spiel starten → **„Mehrspieler“** → Namen und Farbe wählen.
2. Bei **„Übers Internet (mit Code)“** den Code eintippen → **„Beitreten“**.
3. Nach etwa 5–10 Sekunden lädt die Welt des Gastgebers.

## Gut zu wissen

- Gespielt wird immer im Turm des Gastgebers, mit **gemeinsamer Kasse**. Nur der Gastgeber speichert.
  Der eigene Einzelspieler-Stand deines Freundes bleibt unverändert.
- Jeder bekommt beim Beitritt eine **eigene Gondel** an einer eigenen Turmseite (wenn nötig kostenlos).
- Ist deine Seite sauber, drück in der Gondel **H**: du hilfst auf der Seite mit dem meisten Dreck mit. Noch einmal H bringt dich weiter bzw. zurück.
- Höchstens **3 Spieler**. Ein Vierter bekommt „Das Spiel ist voll“.
- Beendet der Gastgeber das Spiel, landen alle anderen mit einer Meldung im Hauptmenü. Der Code gilt dann nicht mehr –
  beim nächsten Mal gibt es einen neuen.
- **„Kein Spiel mit dem Code gefunden“:** Code nochmal genau prüfen (es kommen kein O, I, 0 und 1 vor).
  Läuft das Spiel beim Gastgeber noch?
- **„Keine Verbindung zu Epic“:** Internet prüfen und nochmal versuchen.
- Im selben WLAN geht es auch ohne Code: Bereich **„Im Heimnetz“** mit der angezeigten Adresse.
