## Schnellzugriff

- [[Ideen]] – Ideen-Inbox
- [[Gelernte Fehler]] – Fallen, die schon mal Zeit gekostet haben
- Tagesnotiz: Kalender-Symbol links in der Seitenleiste (landet in `Notizen/Tagebuch`)
- Neue Projektnotiz: Befehl „Vorlage einfügen“ (Strg+P → „Vorlage“) → *Projekt*

## So arbeite ich mit dem Vault

1. Idee → kurz in [[Ideen]] notieren.
2. Wird es ernst → Projektnotiz aus der Vorlage *Projekt* anlegen, mit `[[...]]` auf Baupläne verlinken.
3. Claude Code kann alle Notizen hier lesen und schreiben – einfach sagen „schau in den Vault“.
